# 高級車販売・財務統制 経営統制マスターマニュアル
## 内部統制・資産保全 執行実務書（関係者外秘）

---

### 【はじめに：客観的エビデンスに基づく財務統制の確立】
本マニュアルは、外車・高級車販売事業において発生しうる不正、簿外処理、および私的流用を根絶し、経営基盤の完全な健全化を図るための**「客観的取引照合プロトコル」**の実務執行書です。

ハッタリや感情論、大げさなAI表現は一切排除しています。  
日本の税法（地方税法・自動車重量税法）、銀行口座の入出金記録、USSオークションの客観相場という**「誰にも動かせない公的エビデンス」**を武器に、現場に1ミリも怪しまれずに外堀を埋め、未来の不正を永久に防圧し、過去の損害を1円単位で回収するための手順を記します。

客観的な法的・取引証拠をもとに、相手に悟られず不正を封じ込め、過去の損害を全額回収するための具体的な手順書です。

## 第1章：システムの全体構造と統制フロー

### 1-1. 統制思想：「現場業務DXと統制監査エンジンの分離運用」
- **現場（営業・店舗業務）における運用定義**:  
  地方税法・自動車重量税法・自賠責保険料等の月割実費を自動算定し、成約伝票およびインセンティブ算定を効率化する業務支援ツールとして運用。
- **経営・本部経理における統制定義**:  
  営業担当者が申請した確定成約データをもとに、公的税法マスタ、銀行口座実着金、およびUSS落札相場データと自動突合を実施。差額滞留、口座未着金、査定乖離を1円単位で客観的に抽出する統制コンソール。

### 1-2. 業務執行フロー（5段階の不可逆パイプライン）

```
[ステップ1: 営業担当者]
　成約後、「インセンティブ確定申請書」に車台番号・売価・査定額を記入し本社へ提出。
　（※提出が当月のインセンティブ支給要件となるため、自発的かつ正確に提出される）
　　　↓
[ステップ2: 本社事務担当]
　車検証諸元をDMSシステム（dealer.html）へ入力。
　　・システムが法定税額実費を自動逆算。
　　・預り金との差額を自動算出し、顧客口座への全額返金振込（0円精算）を実行。
　　　↓
[ステップ3: 本社経理]
　信販会社から決定通知書を直接受領 ＆ ネットバンキング入出金記録と照合。
　　・法人口座への実着金を確認（未消込の車両は出庫承認不可）。
　　・下取査定額と直近USS相場データを自動照合。
　　　↓
[ステップ4: 提携行政書士 ＆ 物理的登録ロック]
　システムが発行する暗号化「登録承認トークン」がない申請書類は受任・申請を遮断。
　　・諸費用預り金に差額が残る車両、信販未消込の車両にはナンバーが交付されない。
　　・物理的に登録・出庫ができないため、現金の直抜き納車が遮断される。
　　　↓
[ステップ5: 経営陣によるモニタリング ＆ 事実確認照会]
　エグゼクティブ・コンソールにて財務乖離数値を点検。
　　・統計的乖離が検知された場合、感情論を排した「事実確認照会プロトコル」に基づき証憑提示を要請。
```

## 第2章：システム（DMS Cloud）の運用手順

### 2-1. 統制コンソールへのアクセス
1. **専用URL**:
   ```
   https://pharmacylily7077-sudo.github.io/prompt-dx/dealer.html?mode=owner
   ```
2. **現場端末からのモード切替（非表示ショートカット）**:
   - 現場用通常画面（`dealer.html`）において、画面左上の**「DMSロゴ（エンブレム）」を素早く3回連続タップ（またはクリック）**すると、統制監査機能が表示されます。
   - 現場スタッフへの画面提示時は、上部バナーの**「通常業務画面へ」**をタップすることで、一瞬で監査表示が抑止されます。

### 2-2. 画面上の重要点検指標

| 管理領域 | 点検対象データ | 許容基準・乖離サイン |
| :--- | :--- | :--- |
| **最上部 エグゼクティブバナー** | 諸費用差額滞留・信販未消込債権・査定相場乖離の合算額 | ¥0以外が表示されている場合は即座に対象案件を確認 |
| **車台番号 逆引き監査** | 会計上の粗利不足額、科目別配賦、および特定業者発注集中度 | 同一担当者×特定業者の平均発注額が他社平均の2倍以上超過 |
| **事実確認照会要領** | 客観的な台帳数値・銀行記録・税法マスタに基づく照会文面 | 事実確認照会書文面案をコピーし、証憑原本の提示を要請 |
| **タブ① VSS（成約管理）** | 車両別個別原価（仕入・加修・陸送）および納車前承認ステータス | 諸費用精算・信販着金が未完了のまま納車手続きが進んでいないか |
| **タブ② FAR（諸費用管理）** | 顧客預り金に対する公的税金実費の納付状況および返還残高 | 精算待ち残高が長期間残存していないか（全件0円精算義務） |
| **タブ③ LCS（信販決済）** | 信販決定通知額に対する法人口座着金状況 | 承認後、規定日数を超過しても未消込となっている債権 |
| **タブ④ PMR（実績分析）** | 担当者別の現金決済比率、平均精算日数、および滞留金額 | 現金比率の異常値、精算日数の遅延傾向の把握 |
| **タブ⑤ TRA（過去照合台帳）** | 過去全期間の銀行口座記録と成約台帳の突合照合台帳 | 口座未着金案件、買叩き差額の特定および損害額の確定 |

## 第3章：関係各所に対する体制変更・通達要領

**【運用の原則：監査・横領調査を名目にせず、コンプライアンス遵守を名目とする】**  
すべての体制変更・通達は、**「インボイス制度の厳格遵守」「税務調査対応」「公認会計士・顧問税理士の指導に基づく内部統制強化」**を正当な理由として通達します。

### 3-1. 店舗責任者・営業担当者に対する通達基準文
> **【社内通達文案】**  
> 「顧問税理士および監査方針の改定に伴い、近年の高級車販売にかかる税務コンプライアンス（諸費用預り金、下取査定、および値引き処理）の是正指導を受けました。  
> つきましては、業務の適法性担保および全従業員の適正な業務証明のため、今期より以下の運用を徹底いたします。  
> 1. 成約案件は、車検証コピーを添付した『インセンティブ確定申請書』を成約後48時間以内に本社経理へ提出すること。期日内提出のない案件は、当月のインセンティブ算定対象外となります。  
> 2. 下取車の査定において、市場参考相場（オークション指標）と乖離が生じる事情（修復歴・機関不具合等）がある場合は、状態票を添付のうえ役員の事前決裁を必須とします。  
> 3. 顧客からの成約代金・諸費用の受領は、原則として会社指定口座への銀行振込とし、やむを得ず現金を受領した場合は、当日中に金庫入金し即日預託証を発行してください。」

### 3-2. 本社経理・事務担当者に対する実務指示
現場営業担当者と感情的に対立させることなく、規程に基づき事務的・機械的に処理させます。

1. **諸費用預り金の0円精算プロトコル**:
   - 自動車税・重量税・自賠責保険料等の公的領収証書原本が揃わない限り、精算処理を承認しない。
   - 預り金との差額（余剰金）は、**全件顧客名義の指定口座へ振り込み返金し、預り金残高を必ず「0円」とする**。営業担当者による手渡し返還は規程上禁止。
2. **信販会社（オートローン）の照合プロトコル**:
   - 信販会社（オリコ、ジャックス等）の決定通知書は、営業担当者を経由せず、信販会社より直接経理宛てにPDF等で受領する。
   - ネットバンキング入出金記録と照合し、差額ゼロが確認されるまで出庫パスを発行しない。

### 3-3. 提携行政書士との覚書締結（物理的登録ロック）
不正出庫を物理的に遮断するための決定的な防衛ラインです。提携行政書士と**「コンプライアンス運用覚書」**を締結します。

- **委任条件の改定**:
  「当社の名義変更・新規登録申請において、**本部システムが発行する暗号化登録承認トークン（出庫パス）が添付されていない申請書類は、一切受任・申請を行わないこと**。万が一、現場担当者の個人的な口頭依頼で申請を執行した場合、契約解除および生じた損害の賠償を請求する。」
- **法的効果**:
  行政書士法上の責任を負う専門職であるため、規程外の受任は行われません。これにより、諸費用滞留や信販未着金の車両にナンバーが交付される事態を**物理的に遮断**できます。

### 3-4. 外注修理・整備工場に対する発注基準
営業担当者と外注先の癒着（加修費の水増し請求・架空発注）を遮断します。

- **支払承認条件（税務コンプライアンス名義）**:
  「1回10万円を超える整備・加修・部品交換については、**作業前・作業中・作業後の写真（または交換部品現物確認）および正規納品伝票番号の添付**を支払要件とする。添付のない請求書については、税務上の損金算入否認リスク回避のため経理からの支払手続を実行しない。」

## 第4章：体制移行後に確立される財務統制の客観的効果

| 対象業務 | 従来の構造的課題 | 確立される客観的統制 |
| :--- | :--- | :--- |
| **諸費用預り金** | 「税金等で全額消費した」との口頭報告により差額が不明瞭化。 | 車検証諸元より地方税法・重量税法に基づき法定実費を自動算定。**差額が1円単位で算定され、0円精算完了まで登録承認トークンが発行されない。** |
| **信販・成約代金** | 口頭での承認報告により出庫が行われ、現金回収分が未入金化。 | 銀行口座実着金との消込が完了しない限り、**行政書士が登録申請を受任しないため物理的に納車不可能。** |
| **下取査定** | 主観的な査定報告により安値買叩き・簿外横流しが行われる。 | USSオークション相場データと自動照合。**相場比15%以上の乖離案件は事前決裁なしに出庫承認不可。** |
| **外注加修費** | 作業内容の客観的検証が難しく、過大請求が看過される。 | 写真アーカイブおよび正規伝票の添付を支払要件化。**証憑なき請求の決済を制度的に排除。** |
| **過去の損害解明** | 立証資料が散逸し、法的な損害算定が困難。 | 過去の銀行口座CSVと成約台帳を一括照合し、**「入金欠如」「説明不能な差額」を客観的数値として確定、弁護士・捜査機関へ証拠提出可能。** |
| **経営管理体制** | 現場の言動に疑心暗鬼となり、主観的な確認に終始。 | **公的エビデンスに基づく客観的数値をモニタリング。統計的乖離が検知された場合のみ、標準プロトコルに基づき事務的に証憑提示を照会。** |

### 【結語：公的エビデンスに基づく経営統制の完徹】
取引の適法性と財務の整合性を担保する武器は、**「地方税法・自動車重量税法」「銀行口座実入出金記録」「USSオークション客観相場」という客観的事実**です。

本マニュアルに定めた手順に則り、感情を排して淡々と外堀を埋め、公的証拠をもって組織の健全化と資産保全を遂行してください。
