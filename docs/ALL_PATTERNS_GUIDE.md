## 【パターン群1: 実機画面での検証・操作 全パターン】

ブラウザ（`dealer.html`）上で即座に体験・操作できる全シナリオです。

### パターン1-1: 30年トップ営業部長の不正リスク検知の確認
1. 画面上部のタブ④**「月次粗利監査 & 不正検知」**をクリック。
2. **「フォレンジック行動統計スコアカード」**に注目。
   - 営業部長「神田 孝三」の行に赤色バッジ**【CRITICAL】**が点灯。
   - 諸費用預り金の平均滞留日数が28.4日、特定外注集中度が84.2%、現金比率が58.0%と集計され、横領・リベート・中抜きリスクが極大と判定されていることを確認。
3. **「フォレンジック・トリップワイヤー監視（異常検知）」**に注目。
   - 「諸費用預り金 長期滞留アラート（契約: CT-2026-0801 / 615,800円が18日間滞留）」が即時検知されていることを確認。

### パターン1-2: 物理出庫ゲートロックの作動と強制突破警告
1. タブ①**「車両別成約締め」**をクリック。
2. 契約一覧の1行目（神田部長担当：ポルシェ 911 GT3）の右端にある**「🚪 出庫審査」**ボタンをクリック。
3. **「出庫可否 ゲートキー審査」モーダル**が開く。
   - 判定結果: **【出庫不可（出庫ロック中）】**（赤色表示）
   - ブロッカー理由:
     - ❌ 諸費用預り金残高 615,800円が未精算（手元滞留中）
     - ❌ 信販オートローン着金消込が未完了
   - 正常出庫ボタンは無効化（Disabled）。
4. **「🚨 強制出庫（緊急搬出）」ボタン**をクリック。
   - 確認ダイアログが表示され、強制実行すると「統制違反フラグ（illegalDelivery: true）」が車両データに永久刻印され、統制監査アラートへCRITICAL警告が発報される。

### パターン1-3: 行政書士出庫承認パス（Security Token）の発行・印刷
1. タブ①で、2行目（一条主任担当：メルセデスAMG G63）の右端にある**「🚪 出庫審査」**をクリック。
   - 諸費用残高0円・ローン消込完了済のため、判定結果は**【出庫承認（納車可能）】**（緑色表示）。
2. 緑色の**「📜 行政書士出庫パス発行」**ボタンをクリック。
3. **「専属行政書士 陸運局出庫承認パス」モーダル**が開く。
   - 車台番号（VIN）、発行日時タイムスタンプ、固有セキュリティトークン（例: `AUTH-PASS-C77C`）が生成。
   - セキュリティバーコードおよび「行政書士厳守義務条項（無承認申請は行政書士法違反として懲戒請求）」が表示される。
4. モーダル下部の**「🖨️ 出庫パス印刷」**でA4帳票として印刷可能。

### パターン1-4: 第三者50点パーツ検収アーカイブと「自己監査禁止」
1. 画面右上の**「🛠️ パーツ検収アーカイブ」**ボタンをクリック。
2. 車両を選択（ポルシェ 911 GT3）。
3. 検査員氏名に「神田 孝三」（担当営業マン自身）を入力し、**「パーツ検収記録を保存」**をクリック。
   - 画面にエラー表示: **「【自己監査禁止】担当営業マン自身によるパーツ検収は物理的に禁止されています。」**（登録遮断）。
4. 検査員氏名を「検査員：佐藤（第三者）」に変更して保存すると、正常に50枚写真アーカイブおよび5大アセット照合が確定する。

### パターン1-5: オーナー室直属 年次VIP照合状（親展状）の発行
1. 画面右上の**「✉️ 年次VIP照合状」**ボタンをクリック。
2. 顧客を選択（例: 株式会社エグゼクティブ・キャピタル 御中）。
3. オーナー特命監査室名義の**公式取引照合状**が表示される。
   - 当期購入・売却車両明細および諸費用清算完了額（差額0円）が表示。
   - 「記載のない手渡し現金・裏取引は会社として一切保証せず無効である旨の法的警告」および「オーナー直通特命監査ホットライン」が明記されていることを確認。
4. **「🖨️ 照合状を印刷（親展）」**で郵送用A4用紙として即時出力可能。

### パターン1-6: 法定税額シミュレーターによる1円単位逆算
1. 画面右上の**「⚖️ 法定税額シミュレーター」**ボタンをクリック。
2. 排気量（例: 3,996 cc）、車両重量（例: 1,430 kg）、登録月（例: 9月）、新車/中古を選択。
3. 「法定税額を自動逆算」をクリック。
   - 自動車税（月割）: 32,750円
   - 重量税（3年新車）: 36,900円
   - 自賠責（36ヶ月）: 23,690円
   - **法定税額合計: 93,340円** が1円の狂いもなく算出される。

## 【パターン群3: オーナー直結 Googleスプレッドシート・クラウド同期 全設定パターン】

現場のPCやタブレットから、オーナー個人のGoogleスプレッドシートへリアルタイム自動同期する完全手順です。

### パターン3-1: Googleスプレッドシートの新規作成
1. オーナーのGoogleアカウントで [Google Sheets](https://sheets.new) を新規作成。
2. スプレッドシート名を設定（例: `【極秘】高級車販売DX_オーナー統制台帳`）。

### パターン3-2: Google Apps Script（GAS）のデプロイ
1. メニューの**「拡張機能」>「Apps Script」**をクリック。
2. エディタ内の既存コードをすべて消去し、[`gas/Code.gs`](file:///Users/pha.ai/Documents/antigravity%20optimize/prompt-pha/prompt-dx/gas/Code.gs) の内容をそのまま全コピーして貼り付け。
3. 右上の**「デプロイ」>「新しいデプロイ」**をクリック。
   - 種類の選択: **「ウェブアプリ」**
   - 説明: `高級車販売DX 同期API`
   - 次のユーザーとして実行: **「自分」**
   - アクセスできるユーザー: **「全員」**（認証不要でPOSTを受信するため）
4. **「デプロイ」**をクリックし、表示された**「ウェブアプリのURL」**（`https://script.google.com/macros/s/AKfycb.../exec`）をコピー。

### パターン3-3: システムへのURL登録
1. ブラウザで `dealer.html` を開く。
2. 画面右上の**「☁️ 本部同期」**ボタンをクリック。
3. **「グループ統制本部 Googleスプレッドシート同期設定」モーダル**が開く。
   - 拠点・店舗名: `麻布エグゼクティブショールーム`（任意）
   - GAS Web App URL: コピーしたURLを貼り付け。
4. **「クラウド同期設定を保存」**をクリック。
   - 右上の同期バッジが緑色**「☁️ クラウド同期中」**に変化。

### パターン3-4: 自動記帳される4大シートの確認
同期が作動すると、Googleスプレッドシート側に以下の4つのシートが自動生成され、リアルタイム記帳されます。
1. **`高級車成約粗利台帳`**: 契約番号、車台番号（VIN）、売上総額、総原価、確定粗利、粗利率、営業担当名
2. **`諸費用預り金出納簿`**: 契約番号、VIN、預り総額、法定実費、代行粗利、返還額、手元残高、領収書紐付数
3. **`信販ローン消込台帳`**: 契約番号、VIN、信販会社、ローン元金、実着金額、差額、消込状態
4. **`統制監査アラート台帳`**: 契約番号、VIN、アラート種別、深刻度（CRITICAL等）、内容、担当営業名

> **プライバシー保護規約**:
> 送信ペイロードには顧客の氏名・電話番号・住所は一切含まれず、車台番号（VIN）と契約IDのみが同期されるため、万が一の通信傍受や漏洩リスクに対しても完全安全です。

## 【パターン群4: 組織・店舗への実務導入 全運用パターン（現場告知シナリオ）】

歴30年のベテラン営業マンのプライドを傷つけず、かつ反発させずにシステムを導入するためのコミュニケーション設計です。

### パターン4-1: 現場営業マン向け告知シナリオ（表向きの顔）
- **伝え方**: 「営業マンの事務負担軽減のための最新DXツール」
- **トーク例**:
  > 「これまで面倒だった地方税（自動車税・重量税・環境性能割）の複雑な月割計算を、車検証の数値を入力するだけで1円単位で自動計算してくれるツールを導入しました。お客様への見積提示や諸費用精算書の作成が5分で終わるようになり、電卓の叩き間違いもゼロになります。」
- **効果**:
  営業マンは「便利な計算支援ツール」として歓迎し、自ら進んで正確な数値を入力する。裏でフォレンジック・トラップが作動していることには気づかない。

### パターン4-2: 専属提携行政書士向け運用シナリオ
- **伝え方**: 「コンプライアンス強化と行政書士法人側の免責保護」
- **覚書締結**:
  「当社の登録申請業務においては、システムから発行された固有セキュリティトークン付きの『出庫承認パス』の原本添付を必須とし、これがない書類は受任・申請を行わない」旨の業務委託覚書を締結。
- **効果**:
  営業マンが裏で「先生、急ぎだから先にお願い」と頼み込んでも、行政書士側が「パスがないと懲戒処分になってしまうので絶対に受けられない」と断るため、裏通しが物理的に遮断される。

### パターン4-3: 外注提携先（整備・板金・コーティング）向け運用シナリオ
- **伝え方**: 「インボイス制度およびグループ監査対応のための伝票統一」
- **通知内容**:
  「150万円以上の施工および重整備に関しては、正規の作業明細書および伝票番号の事前照合が完了しない限り、経理からの支払いが実行されません。」
- **効果**:
  架空伝票や水増し伝票によるリベートの原資を物理的に遮断する。

### パターン4-4: オーナー・監査室の日常運用シナリオ
- **朝・夕のチェックルーティン（1分）**:
  オーナーはスマートフォンでGoogleスプレッドシートの「統制監査アラート台帳」を一覧。
  - CRITICALアラートが0件であれば健全。
  - アラートが出ている場合は、誰にも言わずにシステムで車台番号を検索し、出庫ロック状態を確認する。

## 【パターン群5: 帳票出力・エグゼクティブ報告 全パターン】

### パターン5-1: A4横 月次監査報告書の印刷
1. 画面右上の**「🖨️ A4帳票印刷」**ボタンをクリック（またはキーボードの `Cmd + P`）。
2. 印刷プレビューが表示される。
   - 用紙サイズ: A4横（Landscape）
   - ヘッダー: 「極秘・社外秘 高級車販売事業 資金統制・月次粗利監査報告書」
   - 右上: **「グループ統制オーナー決裁印」「内部統制監査室長印」「支店長印」**の3大捺印枠
   - 本文: 車両別成約粗利一覧、諸費用預り金出納精算、信販ローン消込、統制アラート
3. 月末の役員会や顧問税理士への提出資料としてそのまま使用可能。

### パターン5-2: 顧客スマホ直結 公式預り金受領書の発行
1. タブ②「諸費用出納・預り金管理」で、各成約行の**「✉️ 顧客受領書」**ボタンをクリック。
2. 「公式預り金受領証明書」プレビューが表示される。
   - 顧客預かり金総額、法定実費内訳、代行費用、および「差額返還金（0円）」が明記。
3. 「受領書をコピー / 送信」をクリックして顧客へ直接通知。

### パターン5-3: 年次VIP顧客 取引照合状の書留郵送
1. 毎年12月の決算前、画面上部の**「✉️ 年次VIP照合状」**を開く。
2. VIP顧客ごとに照合状をA4印刷。
3. 営業マンを介さず、オーナー特命室の秘書から直接「親展書留」にて郵送する。
