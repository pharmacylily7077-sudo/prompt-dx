## 3. オーナーの実戦チェック手順（たった3ステップ）

毎日・毎週末に、オーナーがやることはこれだけです。難しい操作は一切ありません。

```
【ステップ1】 スマホでシステムを開く
  ↓
【ステップ2】 「諸費用・登録アシスト」タブを見る
  ➔ 「精算残高」が赤字で残っている車両がないか？
  ➔ 残っていれば、営業マンに「この差額の現金、いまどこにあるんや？」と聞くだけ。
  ↓
【ステップ3】 「ローン・信販着金確認」タブを見る
  ➔ 納車間近なのに「会社口座への着金チェック」が入っていない車両がないか？
  ➔ あれば「客から現金預かってへんやろな？通帳記帳見せろ」と言うだけ。
```

## 4. なぜこのやり方で社員がついてくるのか？

1. **社員側は「監視されている」とは夢にも思わない**
   - 画面には「販売サポート」「税額自動計算」「月次表彰ボード」としか書いてありません。
   - 「社長が現場のために使いやすい計算システムを作ってくれた」と感謝します。

2. **清廉潔白にやってる社員は100%守られる**
   - 真面目にやってる営業マンは、税額の計算ミスやお釣りの渡し間違いがなくなり、堂々と「全部正しく精算済みです」と証明できます。
   - 頑張った粗利が「月次表彰ボード」に正当に評価されます。

3. **抜いてる奴だけが勝手に自滅する**
   - 数字を入れれば入れるほど、嘘（帳尻合わせ）が通用しなくなります。
   - オーナーはいちいち現場を疑って怒鳴る必要もなく、画面の数字の不一致を冷静に突くだけで終了です。
