オーナー様、このシステムは**「表向きは社員への信頼と業務支援」**、**「裏ではオーナーが1円の狂いもなく資金と過去の不正を完全掌握する」** という二重構造で設計されています。

```
【表の顔（現場・社員が見る画面）】
  「スマート・セールス＆カーサポート管理システム」
  〜 面倒な諸費用計算や登録を楽にする、会社からの温かいサポートツール 〜
  ※ 社員には「信頼されている」と感じさせ、気持ちよく数字を入力させる。
                             │

【裏の顔（オーナーだけが手元で握る真実）】
```

社員を疑って問い詰める必要はありません。社員には笑顔で「便利なツール作ったから使ってね」と渡し、**オーナー様は手元で静かにすべての真実を把握してください。**

## 2. オーナー様が確認すべき「3大急所」（日々の確認手順）

### 急所1: 【諸費用の手元ネコババ】の確認（タブ②を開く）
- 営業マンが客から現金で受け取った諸費用（自動車税や登録費用など）を、手元に抱え込んで私用に使っていないかを確認します。
- **見方**: 画面上部の **「② 諸費用・登録アシスト」** を開く。
- **判定**:
  - `手元未精算 滞留預り金残高` が **¥0** なら正常。
  - ここに金額が出ている場合、**「営業マンの手元に現金が残ったまま放置されている」** という決定的な証拠です。

### 急所2: 【ローンの口座未着金】の確認（タブ③を開く）
- 「信販会社から会社口座に本当に入金されたか？」を確認します。
- **見方**: **「③ ローン・信販着金確認」** を開く。
- **判定**:
  - バッジに数字が出ていれば、信販会社からの着金消込が完了していません。車だけ先に渡して代金が回収できていないリスクをオーナーが一目で察知できます。

### 急所3: 【納車前の総合関門】（タブ①の「納車前チェック」ボタン）
- 車両一覧の右端にある **「納車前チェック」** ボタンを押すと、裏側で以下の3つが自動判定されます。
  1. 諸費用の預り金が1円残らず0円精算されているか？
  2. ローンが会社口座に着金しているか？
  3. 下取車の査定がオークション相場から不自然に安すぎないか？（安値で買い叩いて裏で転売する手口の防止）
- 条件が揃っていない場合、システムは納車完了を許可しません。

## 3. 【過去数年間の不正を暴く】オーナー専用フォレンジック操作手順

「過去、誰がどれだけ抜いていたのか？」を、**社員に一切知られずにオーナー様の手元だけで調べる** 手順です。

### 手順（所要時間: 3分）

1. オーナーの手元Macでシステムを開き、画面上の **「⑤ 過去取引アーカイブ・一括整理」** タブをクリックします。
2. ツールバーの **「📥 銀行明細CSV / 成約台帳を取り込む」** を押します。
3. 以下のいずれかを取り込ませます：
   - **会社の銀行通帳データ（CSV）**: 三井住友・三菱UFJ・みずほ・りそな等のインターネットバンキングからダウンロードしたCSVをそのまま選択、または貼り付け。
   - **過去の成約Excel**: 過去の契約一覧（日付、金額、担当営業名、諸費用等）をコピー＆ペースト。
4. **「⚡ インポート実行」** をクリック。
5. **システムが自動的に暴き出す内容**:
   - **「台帳には記載があるのに、会社通帳に入金がない取引（手渡し現金の着服・中抜き）」** を全自動で突合し、差額を特定。
   - **「預り金を手元に何十日も滞留させていた取引（私的流用）」** を日数付きでリストアップ。
   - **「当時のUSSオークション相場より異常に安値で下取りされた車（中抜き転売疑惑）」** を抽出。
   - **担当営業別の危険度スコア（誰が一番怪しいか）** を自動ランキング表示。
6. 右上の **「🖨️ A4 取引履歴・整理証明書を出力」** を押すと、いつ・誰が・どの車両で・いくら抜いたかが時系列でまとまったA4帳票が印刷されます。そのまま弁護士や税理士に見せる決定的な証拠書類になります。

> 💡 **今すぐテストで過去の暴き方を確認したい場合**:
> タブ⑤の **「🔄 過去3年間 サンプル整理データを読込」** を押してください。
> 30年のベテラン営業（神田部長）がポルシェやベンツでどのように諸費用を着服し、下取車を相場より450万円安く買い叩いて通帳未入金にしていたかが一瞬で画面に浮かび上がります。

## 4. オーナーGoogleスプレッドシートとの自動連携（スマホで常時監視）

現場のPCやiPadでデータが入力されると、**オーナー様専用のGoogleスプレッドシートにリアルタイムで自動記帳** されます。

- オーナー様は店舗に行かなくても、ご自身のスマートフォンでスプレッドシートを開くだけで、日々の成約・粗利・預り金残高がすべてリアルタイムで見られます。
- 営業マンにはスプレッドシートの存在すら教える必要はありません。

### 連携設定（所要時間: 5分）
1. Googleドライブで新規スプレッドシートを作成（名前: `【極秘】車両販売資金台帳`）。
2. メニュー「拡張機能」→「Apps Script」に `gas/Code.gs` のコードを貼り付けてウェブアプリとしてデプロイ。
3. 発行されたURLを、システム画面右上の **「⚙️ クラウド設定」** に貼り付けて保存するだけです。
*(※ 詳細な画像付き手順は `docs/DEPLOYMENT_GUIDE.md` に記載)*
