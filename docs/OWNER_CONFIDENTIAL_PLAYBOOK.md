## 2. 経営陣が確認すべき「3大内部統制重要項目」（日々の確認手順）

### 急所1: 【諸費用預り金の手元滞留・差額】の確認（タブ②を開く）
- 営業担当者が顧客から現金受託した諸費用（公租公課・登録費用等）が、手元に滞留していないかを確認します。
- **見方**: 画面上部の **「② 諸費用・預り金精算 (FAR)」** を開く。
- **判定**:
  - `手元未精算 滞留預り金残高` が **¥0** なら正常。
  - 金額が計上されている場合、**「営業担当者の手元に預り金残高が滞留している」** 客観的証跡となります。

### 急所2: 【ローンの口座未着金】の確認（タブ③を開く）
- 「信販会社から法人名義口座に着金が完了したか」を確認します。
- **見方**: **「③ ローン・信販着金確認 (LSM)」** を開く。
- **判定**:
  - バッジに件数が表示されている場合、信販会社からの着金消込が完了していません。未着金のまま車両を引き渡すリスクを防止します。

### 急所3: 【出庫承認前の総合ゲート】（タブ①の「出庫審査」ボタン）
- 車両一覧の右端にある **「出庫審査」** ボタンにより、以下の3点が客観的に自動照合されます。
  1. 諸費用預り金が公的領収証照合のもと0円精算されているか
  2. ローン代金が法人口座に着金消込されているか
  3. 下取車の査定額がUSSオートオークション落札相場と大幅に乖離していないか
- 統制要件が充足されない場合、出庫承認は発行されません。

## 3. 【過去取引の客観的検証】フォレンジック照合・分析操作手順

過去の取引台帳および法人口座明細を突合し、客観的な差額・乖離を特定する手順です。

### 手順（所要時間: 3分）

1. 画面上の **「⑤ 内部統制・財務監査 (EAC)」** タブをクリックします。
2. ツールバーの **「📥 銀行明細CSV / 成約台帳を取り込む」** を押します。
3. 以下のいずれかを取り込ませます：
   - **法人口座の銀行入出金データ（CSV）**: 三井住友・三菱UFJ・みずほ・りそな等のインターネットバンキングからダウンロードしたCSVファイルを選択、またはテキスト貼り付け。
   - **過去の成約台帳データ**: 過去の成約実績（成約日、金額、担当者、諸費用等）をコピー＆ペースト。
4. **「インポート実行 ＆ 台帳整理開始」** をクリック。
5. **システムが自動算出・照合する項目**:
   - **「成約台帳に記載があるが、法人口座に入金が確認できない差額案件」** を自動突合して抽出。
   - **「諸費用預り金が長期間滞留していた取引」** を滞留日数付きでリスト化。
   - **「当時のUSSオークション基準相場から統計的乖離のある過少下取取引」** を抽出。
   - **担当者別の財務統制指標（現金決済比率・滞留日数・特定業者集中率）** をスコアリング表示。
6. 右上の **「🖨️ A4 取引履歴・整理証明書を出力」** を押すと、取引日時・担当者・対象車台番号・差額内訳が時系列で整理されたA4照合書が出力されます。弁護士・税理士・公認不正検査士等との事実確認協議における客観資料として機能します。

> **検証用サンプルデータの読み込み確認**:
> タブ⑤の **「🔄 過去3年間 サンプル整理データを読込」** を押下してください。
> 過去取引における諸費用差額の滞留、USS相場からの乖離査定、および法人口座未着金案件が時系列およびマトリクス上に客観的に展開されます。

1. Googleドライブで新規スプレッドシートを作成（名前: `【極秘】車両販売資金台帳`）。

3. 発行されたURLを、システム画面右上の **「⚙️ クラウド設定」** に貼り付けて保存するだけです。
