## 2. iPad / iPhone — ホーム画面アプリ化（PWA）

### 手順（所要時間: 30秒）

1. **Safari** で本番URLにアクセス:
   ```
   https://pharmacylily7077-sudo.github.io/prompt-dx/dealer.html
   ```

2. 画面下の **共有ボタン** (□↑) をタップ

3. **「ホーム画面に追加」** をタップ

4. アプリ名が **「高級車販売DX」** と表示されることを確認し、**「追加」** をタップ

- ステータスバーの色はシャンパンゴールドに統一

## 4. オーナーGoogleスプレッドシート連携（GAS）

### 手順（所要時間: 約5分）

#### ① Googleスプレッドシートを作成
1. https://sheets.google.com で新規スプレッドシートを作成
2. 名前: **「【極秘】高級車販売DX_オーナー統制台帳」**

#### ② Apps Script をデプロイ
1. メニュー **「拡張機能」→「Apps Script」** を開く
2. 既存のコードをすべて削除し、`gas/Code.gs` の内容をコピー＆貼付
3. **保存** (Ctrl+S / Cmd+S)
4. 右上の **「デプロイ」→「新しいデプロイ」** をクリック
5. 設定:
   - **種類の選択**: 「ウェブアプリ」
   - **次のユーザーとして実行**: 「自分」
   - **アクセスできるユーザー**: 「全員（Anyone）」
6. **「デプロイ」** をクリック
7. 発行された **ウェブアプリのURL** をコピー
   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```

#### ③ システムに接続
1. dealer.html の画面で **「⚙️ クラウド設定」** ボタンをクリック
2. **ショールーム名**: 「麻布ショールーム」（任意の名前）
3. **GASウェブアプリURL**: 先ほどコピーしたURLを貼付
4. **「保存」** をクリック
5. ヘッダーのステータスが **「クラウド: 接続正常 ✓」** に変われば成功

#### ④ 本番1台目の登録テスト
1. **「🗑️ 本番データ初期化」** を押してクリーン状態にする
2. **「＋ 新規成約締め登録」** で実際の車両データを1台入力
3. Googleスプレッドシートを開き、以下の4大シートに自動記帳されていることを確認:
   - **高級車成約粗利台帳**: 車種・VIN・粗利・原価が記録
   - **諸費用預り金出納簿**: 預り金の受入記録
   - **信販ローン消込台帳**: ローン契約情報
   - **統制監査アラート台帳**: アラート発報履歴

> ⚠️ **注意**: GAS は `mode: 'no-cors'` でPOSTされるため、ブラウザコンソールに `opaque response` と表示されますが、書き込みは正常に行われています。スプレッドシートを直接確認してください。

## 5. 堅牢性強化機能の使い方

### 💾 バックアップ（エクスポート）
- ヘッダーの **「💾 バックアップ」** をクリック
- `dealer-dx-backup-2026-09-26.json` がダウンロードされます
- チェックサム（CRC32）付きで改竄検知可能

### 📥 復元（インポート）
- ヘッダーの **「📥 復元」** をクリック
- バックアップJSONファイルを選択
- チェックサム検証後、データが復元されます

### 🔒 セッションロック（共有端末向け）
- ヘッダーの **「🔒 PIN設定」** をクリック
- 4桁のPINを設定
- **5分間無操作** で自動的に画面がロック
- PINを入力して再開
- PINを空欄で送信すると解除

### 📡 オフライン対応
- ネットワーク切断時、画面上部に赤いバナーが表示
- データはローカル（localStorage）に保存され、紛失しません
- オンライン復帰時に未送信データを自動リトライ（指数バックオフ）

### 🛡️ データ改竄検知
- 起動時にlocalStorageの整合性ハッシュを自動検証
- 外部ツールやブラウザの開発者ツールでデータを改竄すると即座に警告

## 6. トラブルシューティング

| 症状 | 原因 | 対処 |
|------|------|------|
| GitHub Pages にアクセスできない | Pages が有効化されていない | Settings → Pages で Source を設定 |
| PWAアイコンが白い | キャッシュが古い | Safari の履歴・キャッシュを削除して再追加 |
| スプレッドシートに書き込まれない | GAS URLが未設定 or 権限エラー | 「⚙️ クラウド設定」のURLを確認。GASの「アクセスできるユーザー」を「全員」に設定 |
| 「データ改竄検知」の警告が出る | ブラウザの開発者ツールでデータを直接編集した | バックアップから復元するか、初期化後に再入力 |
| セッションロックのPINを忘れた | — | ブラウザの開発者ツール → Application → Local Storage → `car_dealer_session_pin_v1` を削除 |
| オフラインバナーが消えない | WiFi / LAN が切断中 | ネットワーク接続を確認 |
