## 🏛️ はじめに：気持ちよく仕事をするための会計システム

本システムは、自動車販売事業（乗用車、商用車、輸入車を問わず）において、**「現場のスタッフが清廉潔白に仕事をしていることを誇りを持って証明でき、オーナー・経営陣も安心して事業とスタッフに資金を投入できる」** 信頼の土台を築くために設計された、総合統合会計プラットフォームです。

一般的な乗用車であれば5台、高級輸入車であれば1台——扱う台数や単価が違っても、ビジネスの本質は同じです。お客様から大切なお金を預かり、車を仕入れ、法定費用を納め、信販を着金させ、利益を残す。この当たり前のプロセスを、現場に余計な電卓を叩かせることなくスマートに自動化し、経営と現場の双方が気持ちよく事業に専念できる環境を実現します。

## 💼 5大会計モジュールの構成と役割

人を疑うためではなく、**「誠実な仕事がそのまま1円単位の正確な数字として証明される」** ための5つのスマート機能です。

### ① 【車両成約・個別原価会計】（タブ①）
- **仕入原価・加修整備費・陸送費** を車両（VIN 17桁）ごとにガラス張りに管理。
- 車両本体価格＋オプション売上＋諸費用代行粗利＋信販キックバックから、**確定粗利と粗利率** をリアルタイム自動算出。
- 頭金＋ローン元金＋下取相殺額が契約総額と1円の狂いもなく一致する「代金三方突合」を保証。

### ② 【法定諸費用・預り金出納管理】（タブ②）
- 排気量・重量・登録月から、自動車税（月割）・重量税・自賠責保険料等の**法定税額をシステムが自動逆算**。
- 顧客からの預り金に対し、「公的領収証書番号の紐付いた実費納付」＋「店舗代行粗利」＋「顧客への余剰返還」を行い、**手元残高をピッタリ0円** に収束させます。
- 営業担当者は「自分が預かったお金を1円の過不足なく正しく納め、お客様にお返しした」ことを即座に証明できます。

### ③ 【信販・オートローン着金消込】（タブ③）
- オリコ、ジャックス、アプラス等の信販会社ごとに、**契約元金＋キックバック手数料−取扱手数料＝銀行実着金額** の消込を完全照合。
- 下取車の他社残債立替金の一括返済と回収口座着金の消込追跡も標準装備。

### ④ 【月次決算・財務整合性確認】（タブ④）
- 月次の総売上高、確定粗利総計、平均粗利率、および諸費用預り金の精算サイクルを可視化。
- 納車前の財務承認チェック（諸費用精算0円、信販着金確認、下取適正承認）をクリアした車両のみがスムーズに納車完了へと進みます。
- A4横印刷対応の**公式財務決算書（オーナー決裁印・税理士確認印・店舗責任者印）** をワンクリック出力。

### ⑤ 【過去台帳・通帳照合決算】（タブ⑤）
- 過去の銀行通帳CSV（三井住友・UFJ・みずほ・ネット銀対応）や、過去の成約Excelデータを一括取り込み。
- 過去の取引全件にわたり、**「通帳着金と台帳の完全突合」「預り金精算日数の検証」「下取査定と相場の整合性」** をシステムが自動逆算・照合。
- 過去の財務の健全性を証明する**「A4 財務監査照合証明書」** を印刷出力可能。

## 🔒 データの安全性と現場配慮

1. **プライバシー保護**:
   - 顧客氏名や電話番号などの個人情報は、クラウド送信前に自動スキャンされ、外部には一切送信されません。VINと契約番号のみで安全に管理されます。
2. **共有端末でのセキュリティ**:
   - iPad等を店舗内で共有して利用する場合、ヘッダーの **「🔒 PIN設定」** から4桁コードを登録することで、5分無操作で画面が自動ロックされ、他者による誤操作を防ぎます。
3. **オフライン耐性**:
   - ショールームや屋外で電波が途切れても、データはローカルに安全保存され、オンライン復帰時に自動同期されます。
