# 調剤薬局 売上・入金・返戻管理システム 業務仕様書 (SPEC.md)

## 1. システム概要
本システムは、調剤薬局における日々の締め作業（レジ現金・小口現金・クレジット売上）および2ヶ月サイクルの調剤報酬消込（差額・返戻追跡）を、ブラウザ上で安全かつ簡単に行うための管理システムである。

## 2. 確定した基本方針（職人の引き算）
- **運用フロー**: 営業終了後に、1画面でその日の数字をまとめて入力・即時締める（A案採用）。
- **データ入力**: レセコン連携やCSV取り込みは行わず、伝票やレシートを見ながら数字を手入力する（連携エラーや環境トラブルの撲滅）。
- **セキュリティ**: 患者の氏名・生年月日・処方内容は一切扱わない。返戻・保留の追跡は「カルテ番号」または「ダミー識別子」のみで行う。
- **実行環境**: インストール不要のブラウザ環境（初期フェーズは環境構築エラーのないLocalStorageで動作し、後にクラウド化）。

---

## 3. 機能要件

### ① 小口現金管理
- **機能**: 店舗の日々の経費出納の登録と、現在残高の自動計算。
- **入力項目**: 日付、科目（交通費、消耗品、雑費等）、出金額、入金額（補充）、摘要メモ。
- **計算ルール**: `現在残高 = 前日残高 + 入金額 - 出金額`

### ② レジ現金管理（レジ締め・過不足判定）
- **機能**: レセコン上の窓口売上と、レジ内の実際のお金（実査現金）の突き合わせ。
- **入力項目**: レセコン窓口売上額、実査現金合計額、つり銭準備金。
- **計算ルール**:
  - `過不足額 = 実査現金 - (つり銭準備金 + レセコン窓口売上額)`
  - 判定: 0円なら「一致」、プラスなら「過剰（+〇〇円）」、マイナスなら「不足（-〇〇円、警告色表示）」。

### ③ クレジット決済管理
- **機能**: クレジット端末の日計売上の入力と、決済手数料・純入金見込額の自動計算。
- **入力項目**: クレジット日計売上額、決済手数料率（デフォルト設定: 3.24%、変更可能）。
- **計算ルール**:
  - `決済手数料 = クレジット売上額 × 手数料率（四捨五入）`
  - `差引入金見込額 = クレジット売上額 - 決済手数料`

### ④ 調剤報酬の消込・返戻追跡（2ヶ月サイクル）
- **機能**: 請求月（2ヶ月前）の請求額と、当月の支払基金・国保連からの入金額の差額管理、および返戻・保留案件のステータス追跡。
- **管理粒度**:
  - 月別サマリー: 請求月、請求総額、入金総額、差額。
  - 返戻・保留明細: カルテ番号、請求月、保留金額、事由（保険証無効、疑義照会等）、ステータス（「未対応」「再請求中」「入金済/解決」）。
