# 調剤薬局 売上・入金・返戻管理システム 業務・統制仕様書 (docs/SPEC.md)

---

## 1. システム概要と基本精神

本システムは、調剤薬局における日々の締め作業（レジ現金・小口現金・クレジット売上）および2ヶ月サイクルの調剤報酬消込（差額・返戻追跡）を、ブラウザ上で安全・確実に遂行するための業務管理基盤である。

> **「儲けるためではなく、従業員が稼いだお金と尊厳を守るためのシステム」**  
> 複雑なお金の流れを完全に可視化し、現金のズレや請求放置に対する強力な抑止力とガバナンスを提供する。

---

## 2. 設計思想と組織心理学：なぜ仕様書・取扱説明書にすべてを明文化するのか

本システムおよびドキュメント群は、調剤薬局という特殊な組織における**「人間心理」と「権力関係・面子の力学」**を深く分析した上で設計されている。

### ①「プロの面子を保つ」ための優しさと知識の担保
- 薬局長、管理薬剤師、経営幹部、本部SVなどのリーダー層は、社会的には「医療と経営のプロ」として振る舞うことが求められる。
- しかし現実には、保険請求（レセプト審査機関の深層ルール）や財務会計（インプレストシステム、現金実査の内部統制基準）の細部までを完璧に把握している人間はほとんど存在しない。
- 現代の組織において「知りませんでした」と部下や他者に教えを乞うことは、彼らの立場とプライド（面子）を傷つける。
- したがって、**仕様書や取扱説明書の中に、保険請求の仕組み、会計の約束事、許容される数値の境界線、不正を疑う監査ロジックを余すところなく明文化しておく**。
- これにより、プロを自任する責任者は、誰にも恥をかくことなく自席で密かに確認・学習でき、部下や本部に対しても「本システムとマニュアルの基準通りに統制している」と毅然とした態度で指示を出すことができる。

### ② 現場事務員に対する「見えざる牽制力」と不正の根絶
- 画面を日常的に操作するのは、店舗の医療事務スタッフである。
- 画面UIは「最高級の大人の文房具」として、絵文字や余計な説教バナーを排除した極めてシンプルで清潔な入力インターフェースに徹している。事務員は何のストレスもなく日々の数字を入力できる。
- しかし、**「この入力された数字から、システムと本部が何をどこまで見抜いているのか」の全貌を、現場事務員は理解できない**。
- 一方で、仕様書や業務マニュアルには「どの数字がどうなったら許容範囲で、どのラインを超えたら不正・横領として疑われ即座に監査が入るのか」が厳然たる事実として克明に記されている。
- 「自分には見抜けないが、システムと仕様書の側にはすべてが筒抜けになっている」という構造そのものが、人間の心に魔が差す瞬間を未然に防ぎ、**「そもそも不正を試みることすら不可能な環境」**を作り出す。これこそが薬屋DXが目指す究極の内部統制である。

## 3. 保険請求（調剤報酬レセプト）の仕組みと実務解説

### ① 請求サイクルと「2ヶ月のタイムラグ」構造
調剤薬局の売上の7割〜9割を占める調剤報酬は、患者が窓口で支払う一部負担金（1割〜3割）を除き、審査支払機関を通じて後日入金される。

```
【調剤月】 (例: 7月1日〜7月31日)
   ↓ 窓口で患者から一部負担金を受領（レジ現金／クレジット）
【請求月】 (翌月: 8月10日締切)
   ↓ レセコンから電子レセプトデータを「社会保険診療報酬支払基金（社保）」および「国民健康保険団体連合会（国保連）」へオンライン請求
【審査月】 (当月〜翌月: 8月中旬〜9月上旬)
   ↓ 支払基金・国保連の審査委員会にて、処方箋内容・病名・保険資格の厳格な「原審査」が実施される
【入金月】 (翌々月: 9月20日前後)
   ↓ 審査を通過した確定金額が、調剤薬局の指定銀行口座へ振り込まれる（支払決定通知書の発行）
```

この**「サービス提供から実際の入金まで丸2ヶ月を要するタイムラグ」**こそが、調剤薬局のキャッシュフロー管理を難解にし、入金差額の放置を生む最大の温床である。

### ② 原審査における「差額（返戻・査定・保留）」の発生メカニズム
請求総額と実際の振込入金額が一致しない場合、その差額の内訳は以下の3種類に大別される。

| 区分 | 内容 | 薬局側の対応 | 財務上の扱い |
| :--- | :--- | :--- | :--- |
| **返戻（へんれい）** | レセプトの記載不備、保険証記号番号の誤り、資格喪失後の受診などにより、審査機関からデータが差し戻されること。 | 原因を調査・補正（患者確認や処方元照会）し、**翌月以降に再請求**を行う。 | 一時的な売掛金の回収遅延（再請求により回収可能）。 |
| **審査保留（ほりゅう）** | 疑義照会（過量投与、適応外使用、併用禁忌等）の審査が長引き、当月の支払決定から一時的に除外されること。 | 審査機関からの照会に対する回答・追跡を行う。 | 翌月以降に決定が持ち越される保留金。 |
| **査定（さてい・減額）** | 保険診療のルール（調剤報酬点数表・適応基準）に違反していると判断され、点数が強制的に減額切捨てされること。 | 復活不能なものは損失処理。不当な査定には「再審査請求」を提出。 | 薬局側の過誤による**売上損失（貸倒・雑損失）**。 |

### ③ 返戻再請求の消滅時効と「3ヶ月回収ルール」
- **法的消滅時効**: 健康保険法および民法上の診療報酬債権の消滅時効は**3年**である。
- **実務上の絶対ルール（3ヶ月以内解決）**:
  - 法的には3年であっても、患者の転居・死亡、処方医のカルテ確認不可などの理由により、**発生から3ヶ月を経過した返戻案件の回収率は急激に低下（50%以下）**する。
  - 本システムでは、返戻案件ごとに「カルテ番号・保留金額・発生月・事由・ステータス」を個別に管理し、未対応案件が30日を超えて滞留することを防ぐ。

## 4. 調剤薬局における会計の約束事と統制ルール

### ① あるべき現金（Expected Cash）の方程式
営業終了後のレジ金庫内にあるべき現金残高は、以下の等式によって1円の狂いもなく導き出されなければならない。

$$\text{あるべき現金} = \text{前日繰越つり銭準備金} + \text{本日窓口現金売上（レセコン集計）} - \text{本日レジからの正当な払出（両替等）}$$

本システムでは、この「あるべき現金」と「実査現金（実際に数えた金種別合計）」を突き合わせることで、過不足を即座に特定する。

### ② 現金管理の絶対原則（峻別と私的流用の完全禁止）
1. **売上金と準備金の厳格な峻別**: つり銭準備金（例: ¥50,000固定）は、翌日の営業を円滑に行うための固定資金であり、日々の売上金と混同してはならない。
2. **私的立替・事後相殺の絶対禁止**:
   - 「銀行に行く時間がないから、レジの売上金から一時的に1万円借りて後で返す」
   - 「過不足が出たが、自分の財布から500円足して一致させておく（自腹補填）」
   - これらは刑法上の**業務上横領罪**または**背任行為**を誘発する重大な就業規則違反であり、例外なく厳禁とする。

### ③ 定額資金前渡法（インプレストシステム）による小口出納統制
店舗の日々の消耗品購入、切手代、急な清掃費等は、レジ売上金から支払ってはならず、独立した**「小口現金金庫」**から支払う。
- **インプレストシステム**:
  - 金庫には常に一定額（例: ¥30,000 または ¥50,000）の資金を前渡ししておく。
  - 出金時は必ず「インボイス対応領収書」または「レシート」と引き換えに現金を払い出す。
  - `金庫内の実際現金 ＋ 支払済領収書合計 ＝ 前渡定額` が常時成立していなければならない。
  - 小口現金の過不足は、出金即記帳が原則であるため、**「0円以外は絶対にあり得ない」**のが会計上の大原則である。

## 5. 監査・内部統制基準：数値の許容範囲と「不正を疑う境界線」

現場のスタッフには「丁寧に数えましょう」と伝える一方で、管理者および監査担当者は、以下の**定量的・統計的な境界線**をもって日常の数字を監視・検証する。

### ① レジ現金過不足の監査基準

| 判定 | 数値基準・発生条件 | 現場の解釈 | 管理者・監査の視点（不正検知ロジック） |
| :--- | :--- | :--- | :--- |
| **正常（一致）** | **差額 0円** | 正常終了。 | 理想的な状態。ただし「ピッタリ一致ボタンの濫用による虚偽入力」がないか、定期的な金種実査抜き打ち点検を行う。 |
| **許容範囲（偶発的ミス）** | **1日あたり ±1円〜999円**<br>（月間発生日数 15%以下） | 10円玉・100円玉の渡し間違い、患者の硬貨取り違えなど。 | 統計的に生じうるヒューマンエラー。自腹補填を厳禁とし、発生事実と理由メモをそのまま記録させることでスタッフの心理的安全性を確保する。 |
| **警戒ライン（要調査）** | **1日あたり ±1,000円〜9,999円**<br>または月間発生日数 30%以上 | 千円札の重なり渡し、レセコン入力漏れの疑い。 | 店長または管理薬剤師が当日中にレセコン伝票とクレジット端末レシートを全件照合。 |
| **不正疑いライン（即時監査）** | **① 紙幣単位（-5,000円, -10,000円等）の定額不足の頻発**<br>**② 特定スタッフのシフト日における不足の集中**<br>**③ 恒常的な「過剰（プラス）」の発生**<br>**④ 締め処理後のレセコン取消・修正の多発** | — | **【着服・不正手口の検知】**<br>・紙幣の計画的な抜き取り。<br>・「過剰」は窓口で患者から正規金額を受け取りながら、レセコンを少なく打って現金を余らせ、後で持ち出す手口の予兆。<br>・締め後の処方箋取消による現金抜き取り。防犯カメラ照合および本部特別監査を発動。 |

### ② 小口現金の監査基準

| 判定 | 項目・状態 | 監査・内部統制上の判断基準 |
| :--- | :--- | :--- |
| **許容範囲** | 領収書・レシート完備の少額出金（1件数千円以内） | 消耗品、文具、患者用衛生用品、切手等の正当な店舗運営経費。インボイス登録番号の確認。 |
| **警戒ライン** | 領収書のない「出金伝票（メモ書き）」の残高 | 慶弔費や急な自販機購入等を除き、月累計5,000円以上のメモ出金は原則認めない。速やかな領収書回収を指導。 |
| **不正疑いライン** | **① 私的物品の混入**（菓子・タバコ・私用雑誌・高級文具等）<br>**② 金額の水増し・同一レシートの二重請求**<br>**③ 手元実査現金と台帳残高の不一致（1円でも）** | 私的経費の付け回しは背任・着服行為。小口現金の不一致は即座に金庫管理者からの聞き取り調査および全領収書監査を実施。 |

### ③ 調剤報酬消込・返戻の監査基準

| 判定 | 数値基準 | 管理者・監査の視点 |
| :--- | :--- | :--- |
| **健全水準** | 返戻保留額が月間請求総額の **0.5%未満** | 窓口での保険証確認、資格確認端末の運用が極めて高精度に行われている状態。 |
| **許容範囲** | 返戻保留額が月間請求総額の **0.5%〜1.0%** | 月末の保険証切替や転職等に伴う不可避な資格喪失エラーの許容範囲内。 |
| **警戒ライン** | 返戻保留額が月間請求総額の **1.0%〜2.0%** | 窓口事務の資格確認フロー、記号番号入力精度の低下。改善指導を実施。 |
| **不正・怠慢ライン** | **① 返戻保留額が請求総額の 2.0%を超過**<br>**② 未対応ステータスのまま30日以上放置された案件の存在**<br>**③ 原因未特定差額（不明差額）の放置** | 事務スタッフによる返戻通知書の隠蔽、再請求業務の職務怠慢、または架空請求による査定差額の可能性。直ちにカルテ番号ごとの全件調査を実施。 |

## 6. システム機能仕様一覧

### ① 本日の日計締め（タブ①）
- レジ現金（準備金・窓口現金売上・実査現金）の突合照合
- 電卓不要の金種カウンター（10,000円〜1円、小計自動計算・反映）
- クレジット売上および決済手数料（初期値3.24%）の自動控除・純入金見込算出
- 定型理由メモタグのワンタップ入力
- 温かい労いモーダル（締め完了サマリー、翌日の準備金案内）

### ② 小口現金管理（タブ②）
- 出金（経費精算）・入金（金庫補充）のリアルタイム残高計算
- 科目別集計およびワンタップかんたん入力プリセット
- インプレストシステムを担保する手元現金照合

### ③ 調剤報酬消込（タブ③）
- 請求月と入金月の2ヶ月タイムラグ差額管理
- カルテ番号単位の返戻・保留追跡台帳（未対応／再請求中／解決）
- ワンタップ事由入力（資格喪失、記号番号誤り、疑義照会等）
- 個人情報非保持（患者氏名・個人情報の入力自動遮断）

### ④ 月次集計レポート ＆ A4帳票印刷（タブ④）
- 月間横断集計（総売上、純入金、過不足累計・発生日数、小口出納、返戻未解決額）
- 店長確認印・本部受領印欄付きA4帳票出力（CSS改ページ泣き別れ防止対応）

### ⑤ バックアップ＆リストア（ヘッダー）
- 全データ（小口・レジ・消込）の単一JSONファイルエクスポート
- 個人情報非保持ディープスキャン（患者氏名混入時のインポート遮断）

### ⑥ 本部リアルタイム同期（クラウド連携）
- Google Apps Script（`gas/Code.gs`）を通じたGoogleスプレッドシートへの即時自動記帳
- オフライン保護（通信エラー時の自動キュー保管と再送）
