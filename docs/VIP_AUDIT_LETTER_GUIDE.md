# 年次VIP顧客 取引照合状（残高確認書）運用実務マニュアル

本書は、社内システムに一切記帳せず顧客の車両を外部へ横流しする「簿外取引（完全未記帳）」を、**顧客側からの自発的な照会によって無血で特定する**ための公式文書の仕様および運用手順書です。

---

## 1. 結論：「こんなことを書いてもいいのか？」に対する回答

### 結論：元の文面は絶対にNG（不可）です

```
【元のNG文面】
万一、本状に記載のないお取引、担当営業マンによる個人口座へのお振込み案内、手渡し現金の受領、または「社外の専門業者への直接売却の斡旋（闇飛ばし）」等がございましたら、弊社公式保証および法的免責の対象外となりますので、直ちに上記オーナー直通ホットラインまでご一報ください。
オーナー直通特命監査ホットライン（24時間守秘義務受付）: ...
```

### なぜ書いてはいけないのか（3つの致命的欠陥）
1. **会社の信用・ブランド価値の自爆**:  
   富裕層顧客に対して「闇飛ばし」「手渡し現金」「法的免責」といった犯罪捜査のような言葉を突きつけると、「この会社は社内で横領や不正が横行している危険な店なのか」という強烈な不信感を与え、二度と取引してくれなくなります。
2. **顧客と営業マンの心理的結束を強めてしまう**:  
   長年信頼している営業マンを犯罪者予備軍扱いするような書面は、顧客に不快感を与え、「営業マンをいじめている会社」と見なされて競合他社へ顧客ごと流出します。
3. **安っぽく、下品な印象**:  
   一等地で数千万円の高級車を扱う正規インポーターやメガディーラー（コーンズ、ヤナセ等）は、このような露骨な脅し文句を顧客に向けた公的文書に絶対に使いません。

## 3. 具体的な使い方・運用手順マニュアル

この照合状は、単なる手紙ではなく「営業マンの完全未記帳取引（簿外売却）を無血で炙り出す仕掛け」として機能します。以下の手順を厳守して運用します。

```
［本社・代表取締役室］
        │
        ├─【親展郵送】─▶ ［顧客（富裕層VIP）］
        │                     │
        │                     │ 「先月売った車が一覧に載っていない」
        │                     ▼
        │             ［顧客から本社へ照会］
        │                     │
        ▼                     ▼
［客観的証拠の確保］◀─── 「照会があったので確認している」と中立に事実究明
```

### ステップ1：出力（年1回または疑義発生時）
- システム画面（タブ⑤またはオーナーコンソール）の 「VIP年次取引照合状を出力」 ボタンを押下。
- 該当顧客、または全顧客の当年取引実績（成約車・下取車・諸費用返還額）が記載されたA4書面を生成・印刷。

### ステップ2：親展郵送（※ 最重要：営業マンを完全バイパス）
- **絶対に担当営業マンに手渡しや郵送を依頼してはなりません**。
  - 営業マンに預けると、自分が中抜きした顧客宛のレターを途中で抜き取って破棄します。
- 必ず**本社総務部または代表取締役室から直接、顧客の自宅・法人所在地へ「親展」にて郵送（簡易書留またはレターパック）**します。

### ステップ3：送付時期（顧客に自然に受け入れられるタイミング）
- **推奨時期**:
  1. **年次決算期（毎年一定の月）**: 「年次の会計監査および登録内容確認」として送る。
  2. **年末年始・新年のご挨拶**: 「本年のご愛顧の御礼とご登録内容の年次確認」として送る。
  3. **車検・12ヶ月点検のご案内時**: 「保証継承および定期点検ステータスの確認」として同封。

### ステップ4：顧客側からの自発的照会の発生（無血の特定）
もし営業マンが、顧客から車を個人的に買い取って外部ブローカーに転売していた場合（会社システムに一切未記帳）：
1. 顧客は届いた照合状を見て、「あれ？先月担当の神田さんに売ったフェラーリが、この公式一覧に載っていないぞ？」と違和感を持ちます。
2. 照合状には「記載のない取引は保証登録対象外となる場合がある」と上品に書かれているため、顧客は愛車の保証や税務処理を心配し、**書面に記載された直通窓口へ自発的に電話・メールをしてきます**。

### ステップ5：事実確認と外堀埋め（オーナー側の対応）
- 顧客から「先月手放した車の記載がない」と連絡が入った時点で、**客観的な不正（簿外取引）が確定**します。
- オーナーは営業マンに対し、疑って問い詰めるのではなく、極めて冷静に以下のように照会します：
  > **社内照会トーク案**:  
  > 「〇〇様から本社のコンプライアンス窓口に、『先月売却した車両が年次照合状に反映されていない』とお問い合わせが入っている。手続き漏れの可能性があるため、当時の契約書、預り証原本、および代金の受領・送金記録を本日中に提出してください。」
- 相手は「顧客が会社に問い合わせた」という事実の前では言い逃れができず、白日のもとに事実が露呈します。
