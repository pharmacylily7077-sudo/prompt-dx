# 外車・高級車販売事業 資金統制・不正根絶システム 統制仕様書 (docs/CAR_SALES_SPEC.md)

**〜業界歴30年のトップセールスマンによる巧妙な不正・中抜きを物理的・数学的に封殺する統制フレームワーク〜**

---

## 1. システム概要と統制思想

本システムは、多角経営グループにおける高級車・インポートカーディーラー事業（ロールスロイス、フェラーリ、ポルシェ、メルセデスAMG等）を対象に、日々の成約締め、諸費用出納、オートローン消込、および月次粗利監査を統制する基盤である。

> **「車格に相応しい気品ある文房具であり、裏側は1円の逃げ場も許さない防犯センサー」**  
> 現場営業マンには電卓すら叩かせない5分のシンプル操作性を提供しつつ、裏側では動かせない第三者外部証拠（税務署、陸運局、USSオークション相場、信販会社、富裕層顧客自身）で四方から挟み撃ちにし、魔が差す心理を根絶する。

## 2. 相手（歴30年トップセールスマン）の欺瞞手口と「6大フォレンジック・トラップ」

### なぜ、従来の管理では30年のベテランに欺かれるのか？
1. **富裕層顧客との強固な信頼**: VIP顧客は「〇〇さんに任せてあるから」と数十万〜数百万円の現金を無防備に手渡す。
2. **社内の聖域化（アンタッチャブル）**: 多額の粗利を稼ぎ出すため、若手店長や経理担当者が強く追及できず、領収書の提出遅延が常態化する。
3. **下請け業者（板金・整備・コーティング）との裏リベート**: 架空・水増し伝票を切らせ、差額を現金バックさせる。
4. **下取車の過小査定・闇転売**: オークション相場を偽って安く買い叩き、外部ブローカーに転売して差額を中抜きする。
5. **預り金の玉突き自転車操業**: A顧客の預り金を私用（借金返済等）に使い、B顧客の頭金でA顧客の税金を納付する。

### これを物理的・数学的に封殺する「6大フォレンジック・トラップ」

```
                    【顧客（富裕層VIP）】
                             │  ▲
              現金手渡し     │  │  ② オーナー名義の公式受領通知
             （裏握り）      │  │ （システムから顧客スマホへ直結）
                             ▼  │
【歴30年トップ営業】 ───▶ [ 納車ゲート ] ◀─── ①【陸運局・税務署】
        │                    │                （法定税額マスタ照合）
        │                    ▼
        │             ③ 物理出庫ロック
        │            （預り金残高>0なら納車不可）
        ▼
   提携工場・外注先 ───▶ ⑤ レバレート・部品代自動監査
 （キックバック水増し） （市場標準価格との乖離検知）
        │
        ▼
   ④ USSオークション相場突合（下取車の過小査定・闇転売阻止）
   ⑥ 営業マン別フォレンジック行動統計（滞留日数・現金比率・粗利歪み検知）
```

#### ① 法定税額自動逆算マスタ（数字改ざんの封殺）
- 営業マンが入力する諸費用内訳を信用せず、排気量・車両重量・登録月・年式から法律上の公的税額（自動車税・重量税・環境性能割・自賠責）をシステムが自動逆算。
- 顧客からの預り総額と公的税額の差額（余剰金）を強制特定し、手元現金の隠蔽を不可能にする。

#### ② 顧客直結バイパス受領通知（二重契約・中抜きの即死トラップ）
- 諸費用や頭金を受領した瞬間、オーナー・会社公式名義で顧客のスマホ・メールへ「公式預り金受領証明書（法定実費内訳および余剰返還額）」が直接発行される。
- 営業マンが顧客から裏で受け取った金額と会社計上額に1円でもズレがあれば即座に露呈する。

#### ③ 物理出庫ゲートロック（預り金残高ゼロ原則）
- 諸費用預り金残高が「1円単位で0円」かつ「全法定レシート番号登録済」「ローン着金済」でなければ、車両ステータスを「納車完了（出庫）」に変更できない。
- ロックを無視して出庫させた場合、システムは「🚨違法出庫アラート」をオーナー直結で発令する。

#### ④ 下取車 USSオークション基準相場突合
- 下取査定額をオートオークション基準相場（USS落札平均データ）と突合。相場より15%以上低く買い取っている場合、オーナーの個別承認なしには契約成立させない。

#### ⑤ 加修・オプション外注の工賃（レバレート）統制
- 提携外注先への整備費・加修費が車両価格の15%超または150万円以上の高額整備である場合、外注伝票番号および明細の登録を義務付け、架空リベートを排除する。

#### ⑥ 営業マン別フォレンジック行動統計スコアカード
- 「平均預り金滞留日数」「現金決済比率」「特定外注集中度」を統計集計し、不正リスク指数（NORMAL / ELEVATED / CRITICAL）を算出。

## 3. 数理ロジック・方程式

### 1. 成約代金三方突合の方程式
$$\text{契約総額} = \text{頭金（現金/振込）} + \text{オートローン元金} + \text{下取車相殺額}$$
- 1円の不整合も保存を許可しない。

### 2. 車両別個別原価・確定粗利の方程式
$$\text{個別総原価} = \text{車両仕入原価} + \text{加修整備原価} + \text{陸送費用}$$
$$\text{売上総額} = \text{車両本体価格} + \text{販売オプション売上} + \text{諸費用代行粗利} + \text{ローンキックバック}$$
$$\text{確定粗利} = \text{売上総額} - \text{個別総原価}$$
$$\text{粗利率} = \frac{\text{確定粗利}}{\text{売上総額}} \times 100\%$$

### 3. 諸費用預り金三方突合の方程式
$$\text{手元預り残高} = \text{顧客預託総額} - (\sum \text{公的納付実費（レシート番号必須）} + \text{店舗代行売上} + \text{顧客返還額})$$
- 納車完了時の絶対条件: $\text{手元預り残高} = 0\text{円}$。

### 4. オートローン入金消込の方程式
$$\text{実着金額} = \text{契約ローン元金} + \text{キックバック手数料} - \text{信販取扱手数料}$$
- $\text{実着金額} - (\text{元金} + \text{キックバック} - \text{手数料}) = 0\text{円}$（未特定差額ゼロ原則）。

## 4. 組織心理学と免責のための絶対的ガバナンス

1. **画面は「最高級万年筆」の品格**:  
   画面には説教がましい標語や警告枠を乱立させず、オックスフォードネイビーとシャンパンゴールドの静謐なエグゼクティブデザインに徹する。
2. **「何が見抜かれているか分からない」抑止力**:  
   営業マン側には親切な計算支援ツールに見えるが、裏側では本仕様書に定義されたフォレンジック・アルゴリズムが常時作動し、オーナーのスマートフォンへリアルタイムに直結している。
3. **当局・顧問税理士への完全免責エビデンス**:  
   車台番号（VIN 17桁）単位で仕入伝票、公的納税レシート、顧客返還振込、信販振込通知書が1円の狂いもなく紐付けられたA4横印刷帳票を出力可能。税務調査や公的監査において「一切の使途不明金が存在しないこと」を完全立証できる。

## 5. 【至高の防護・最終防衛線】システム外の闇ルートを断ち切る3大包囲網

業界歴30年のトップセールスマンがシステム（画面）の入力すら迂回しようとした場合に作動する、**「現場の物理・法的手続き・富裕層顧客」を巻き込んだ最終防護網**である。

### ① 【急所1 闇飛ばし封殺】 オーナー室直属 年次VIP顧客 取引照合状（親展状）
- **対象手口**: 会社を通さず客の車を外のブローカーへ直接売却させ、現金謝礼を中抜きする「闇仲介」。
- **統制機構**:
  - 毎年12月、会社の全顧客に対し、営業マンを完全に介さず、代表オーナー室より「公式お取引実績一覧（購入・売却・諸費用）」を親展郵送。
  - 「記載のない取引やお乗り換えがある場合は保証適用外となるため、オーナー直通ホットラインへご一報ください」と明記。
  - 営業マンは裏取引が年末に100%露呈することを悟り、闇仲介を企てること自体を完全に諦める。

### ② 【急所2 書類裏通し遮断】 専属行政書士用 陸運局出庫承認パス（Security Token付）
- **対象手口**: 未精算のまま昔馴染みの行政書士に書類を渡し、陸運局で勝手に名義変更・登録を通す手口。
- **統制機構**:
  - 提携行政書士法人と「統制覚書」を締結。
  - システムが出力する**「出庫承認パス（Security Token: `AUTH-PASS-XXXX`）」**が原本添付されていない申請書類は受任・申請厳禁とする。
  - 出庫承認パスは、諸費用預り金残高が「1円単位で0円」かつローン着金が消込完了していない限りシステム上発行不可。

### ③ 【急所3 パーツ中抜き防止】 第三者専任検査員による50点パーツ検収アーカイブ
- **対象手口**: PCCBカーボンブレーキ、鍛造ホイール、チタンマフラー、内装カーボン等の高額純正オプションのすり替え・横領。
- **統制機構**:
  - 車両の入庫時および納車直前に、第三者の専任検査員（整備士・事務員）が5大アセット（ブレーキ、ホイール・DOTコード、マフラー、内装、ECU）を点検し、高精細デジタル写真50枚をアーカイブ。
  - **「自己監査の絶対禁止規約」**: 担当営業マン自身が検査員として登録しようとした場合、システムが例外をスローして登録を遮断する。
