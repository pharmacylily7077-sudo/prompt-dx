# 多角経営グループにおける不正根絶・内部統制ガバナンスシステム 導入提案仕様書 (docs/EXECUTIVE_PROPOSAL.md)

**〜現場のブラックボックスを完全解体し、数億円規模の不正・隠蔽を物理的に不可能にする統制フレームワーク〜**

---

## 【第1部】エグゼクティブ・サマリー（3分で把握できる要点）

### 1. なぜ、オーナーの知らないところで「数億円の不正」が起きたのか？
- **多層構造による報告の遮断（隠蔽の温床）**:  
  現場スタッフ → 主任・サビ管 → 施設長・事務長 → 本部幹部 → オーナー。  
  情報が届くまでに多数の中間フィルターが存在し、現場の小さなズレや意図的な改ざんが「自分たちの保身」のために握りつぶされ、報告が意図的に止められていました。
- **一般的な会計ソフトの限界（盲点）**:  
  弥生、freee、勘定奉行などの会計ソフトは、「提出された領収書や通帳から税金の計算書を作る」のが目的であり、**「現場の伝票が事実かどうか」「給付費の架空請求や現金の抜き取りがないか」を疑う機能は一切ありません。**

### 2. 本システムが実現する「絶対的ガバナンス」の3原則
1. **中間管理職の報告ルートを完全バイパス（オーナー直結）**:  
   現場が日々の数値を確定した瞬間、**途中の上司が数字を改ざん・もみ消しする隙を与えず、オーナーのスマホ・PC（Googleスプレッドシート）へリアルタイムに直結同期**されます。
2. **数字の逃げ場を塞ぐ「外部データとの三方照合」**:  
   店舗・事業所が入力した数字を信用せず、**「国保連・支払基金の入金データ」「レセコン・実績記録」「手元の金種実査」**という、誰も改ざんできない外部証拠で四方から挟み撃ちにして不整合を1円単位で検知します。
3. **現場は5分の「使いやすい文房具」、裏は「逃げられない防犯センサー」**:  
   現場のスタッフには電卓すら使わせない親切で簡単な操作性を提供しつつ、裏側では「何がどこまで見抜かれているか分からない」という強烈な抑止力を効かせ、魔が差す心理を根絶します。

## 【第2部】詳細な仕組み：なぜ現場の不正が100%不可能になるのか

本システムは、**4つの「不可逆ゲート（通過せざるを得ない関門）」**によって不正を物理的・数学的に遮断します。

```
[現場の入力] (日計売上・実査現金・公費請求)
     │
     ▼ 【ゲート1: あるべき現金・三方照合】
        独立した複数データと即時突合。1円でもズレがあれば即座に赤字警告
     │
     ▼ 【ゲート2: 2ヶ月タイムラグ公費消込】
        国保連・支払基金の振込通知書と完全突合。「原因未特定差額」を許さない
     │
     ▼ 【ゲート3: 組織バイパス・リアルタイム同期】
        中間報告ルートを一切通さず、オーナーの手元へ瞬時にクラウド自動記帳
     │
     ▼ 【ゲート4: 統計的パターン分析】
        「特定シフト」「紙幣単位の不足」「返戻の放置」をシステムが自動炙り出し
```

### ゲート1：あるべき現金（Expected Cash）の方程式
現場の金庫にあるべき現金は、以下の客観式で導かれます。
$$\text{あるべき現金} = \text{前日繰越準備金} + \text{本日売上実績} - \text{正当な領収書のある小口出金}$$
- 現場スタッフは電卓を使わず、金種カウンター（1万円札〜1円玉の枚数）を入力するだけ。
- 「自腹で補填して合わせる」「メモ書きで現金を抜く」といった行為は、金種バランスの不整合や未特定差額として即日検知されます。

### ゲート2：公費（国保連・支払基金）の「2ヶ月消込」と差額0円原則
- 調剤報酬や就労支援給付費は、請求から振込まで2ヶ月のタイムラグがあります。
- 請求額と入金額に1円でも差額がある場合、本システムは**「利用者・カルテ番号ごとの事由（資格過誤、減算保留等）」と完全に一致して「未特定差額 0円」になるまで、絶対に合格サインを出しません。**
- 不正な過大請求や架空請求による「査定減額」が発生した場合、隠蔽することは不可能です。

### ゲート3：中間管理職を無力化する「直結クラウド同期」
- 店舗や事業所で「保存」ボタンが押された瞬間、Google Apps Scriptを経由して、**オーナー専用のスプレッドシートに新しい行として自動書き込み**されます。
- 途中で施設長や事務長が「今月の数字はまずいから書き直そう」と介入することは技術的に不可能です。

### ゲート4：組織心理学に基づく「見えざる牽制力」
- 画面上には説教がましい警告や絵文字は一切なく、上質な大人の文房具に徹しています。
- しかし、仕様書（`docs/SPEC.md`）には「どの数字がどうなったら不正を疑い即時監査に入るか」が克明に書かれています。
- **「自分の入力した数字から、本部とオーナーが何をどこまで見抜いているのか分からない」**という底知れぬ構造が、現場から不正の選択肢を完全に奪います。

## 【第3部】何がどうわかるのか？（事業別検知マップ）

### 1. 【就労支援A型施設】：数億円規模の不正・架空請求の完全遮断

| 不正・トラブルの手口 | 従来の管理（なぜ数億円まで膨らんだか） | **本システム導入後に暴かれること・防げること** |
| :--- | :--- | :--- |
| **給付費の架空・水増し請求**<br>（出席していない利用者の実績改ざん） | 国保連からの入金通帳を事務長が握り、請求書と入金額の突合をオーナーが見ていなかった。 | **国保連請求額と入金額の全件消込を強制**。<br>実績記録票の出席日数と給付費請求額が1名単位で連動し、架空請求による「返戻・保留・過誤調整」が発生した瞬間にオーナーの画面に赤字で通知される。 |
| **生産活動と給付費の混同**<br>（赤字補填の違法運用） | 生産活動（売上）の現金出納がブラックボックスで、利用者の賃金がどこから出ているか不明確だった。 | **「生産活動売上」と「小口出納」を完全独立管理**。<br>日々の製品売上、カフェ・作業売上の現金実査を毎日突合し、生産活動収支の乖離を一撃で可視化。 |
| **利用者の工賃・賃金のピンハネ・未払い** | 手渡し現金や日払い賃金の台帳が現場のノート管理だった。 | **手元現金と出納残高の1円のズレも許さないインプレスト管理**により、現金の抜き取りや使途不明金を物理的に根絶。 |

---

### 2. 【調剤薬局】：赤字薬局を黒字転換させた実証済みガバナンス

- **レジ現金過不足の即時特定**:  
  窓口売上と実査現金を毎晩突合。紙幣単位の不足（抜き取り）や、レセコン事後取消による着服を即日検知。
- **返戻金（売掛金）の回収漏れ防止**:  
  支払基金からの入金差額をカルテ番号単位で追跡。机の引き出しに眠っていた返戻金を時効前にあぶり出して現金化（薬局の利益直結）。
- **小口現金の私的流用根絶**:  
  領収書のないメモ出金や私物購入をシステムが排除。

---

### 3. 【外車販売・医療ビル】：預り金着服と滞納隠蔽の防止

- **外車販売（諸費用預り金）**:  
  顧客から預かった自動車税・重量税・印紙代等の現金と、実際の納税レシートを1台ごとに紐付け。営業マンによる私的流用・自転車操業を完全遮断。
- **医療ビル（テナント管理）**:  
  クリニックごとの賃料・共益費・水光熱費按分の請求と着金を毎月消込。テナントの未払い・遅延の隠蔽を即日露呈。

## 【第4部】当局・弁護士対応：組織防衛と免責のための「決定打」

現在、オーナー様が直面されている捜査・監査において、**最も強力な武器**となります。

1. **「組織的な隠蔽ではなかった」ことの立証**:  
   現場管理職が報告を遮断していた構造を論理的に説明し、オーナー自らが直ちにこの厳格な統制システムを導入した事実を示すことで、**オーナー個人の善管注意義務違反・悪質性の追及を大幅に減免**させる法的エビデンスとなります。
2. **行政処分（指定取消し）を回避するための「再発防止策」の提出**:  
   自治体や厚生労働省が最も重視するのは「口先だけの反省」ではなく、**「二度と不正ができない物理的システムの構築」**です。本仕様書（`docs/SPEC.md`）および本システムの実稼働実績を再発防止策として提出することで、事業継続（指定維持）への道を切り拓きます。

本システムは、数千万円かかる大掛かりなサーバー構築やアプリインストールを必要としません。**ブラウザとGoogleスプレッドシートのみで、即日稼働**します。

```
[Day 1: 即日]  調剤薬局での稼働確認・オーナー専用統制スプレッドシートの開設
      ↓
[Day 2: 翌日]  就労支援施設・外車部門へのヒアリングおよび入力フォーム最適化
      ↓
[Day 3: 3日後] 全拠点の現場スタッフへの入力展開 ＆ オーナーのスマホ監視開始
```

**「誠実に働くスタッフを守り、不正を働く者に数字の逃げ場を与えず、オーナーの人生と事業を完全防衛する。」**  
そのための準備は、すべて整っております。
