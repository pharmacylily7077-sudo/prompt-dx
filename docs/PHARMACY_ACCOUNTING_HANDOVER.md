### 2. 薬局会計における「4大急所」と数学的包囲網（設計方針）

| 領域 | 現場スタッフの手口（抜かれる原因） | 数学的包囲ロジック（システムで塞ぐ仕組み） |
| :--- | :--- | :--- |
| **① 窓口一部負担金<br>（レジ現金）** | レセコンの請求額とレジ現金の差額を「未収金」「患者の持ち合わせ不足」と偽ってポケット直抜き。 | レセコン日計表（確定点数×負担割合）とレジ現金を日次突合。未収金は患者名・連絡先・回収期日必須、差額は即日アラート。 |
| **② 小口現金出納<br>（店舗運営費）** | 「備品を買いました」「消耗品代です」と領収書のない手書きメモで処理し、毎月数万円ずつネコババ。 | インボイス登録番号付き公的レシート・領収書原本のない出金はシステムが受任拒否。月次で必ず残高0円精算。 |
| **③ 調剤報酬（社保・国保）<br>口座着金消込** | レセプト返戻・査定減額を隠蔽・放置し、「まだ振り込まれていません」と嘘をついて資金を滞留させる。 | 支払基金・国保連の「請求決定通知書原本」と銀行通帳CSVを自動突合。請求額と実着金額の差額（返戻金）を1円単位で可視化。 |
| **④ 高額医薬品在庫<br>（薬剤出納）** | 抗がん剤や生物学的製剤などの高額薬を架空廃棄・棚卸誤差にして裏で横流し。 | レセコン処方データ（出庫）と納品書・伝票（入庫）から理論在庫を自動算出。実在庫との棚卸乖離率を検知。 |

### 3. 外車システムから薬局システムへ移植・実装すべき機能
1. **エグゼクティブ・バナー（最上部）**:
   - スマホで開いた瞬間に「窓口レジ使途不明金」「小口未精算残高」「レセプト未着金・返戻放置額」が赤文字で一目でわかる。
2. **神の一手（必殺カンペ集）**:
   - 不審な事務員や管理薬剤師に対して、暗算不要でそのまま口にするだけのキラーフレーズ自動生成。
   - （例：「〇〇さん、先月の小口現金の残高〇万〇円、税理士からレシート原本がないって指摘来てるんだけど領収書どこ？」）
3. **現場完全ステルス（現場用画面とオーナー専用コックピットの分離）**:
   - 医療事務員に見せる画面からは「三方突合」「横領」「監査」などの言葉を全滅させ、「日次レジ締め・小口出納DX」という清潔な日常業務の顔にする。
   - オーナーモード（`?mode=owner` またはロゴ3回タップ）でのみ全透視画面を全開放。
