# 調剤薬局システム 開発憲法（Rules）

## 1. セキュリティ規約（絶対厳守）
- 患者の個人情報（氏名、生年月日、電話番号、住所、処方詳細等）は一切取り扱わない。
- 返戻・保留の対象は「カルテ番号（例: A001, 1024等）」または「ダミー識別子」のみで管理すること。

## 2. 開発・実行環境方針
- 初期開発は、環境構築トラブルを避けるため「ブラウザ完結（HTML / CSS / JavaScript / LocalStorage）」で動作させること。
- インストール作業やDocker・データベース設定を要求してはならない。ブラウザでファイルを開くだけで即座に動く形を維持すること。

## 3. 実装とテストの掟
- 見た目の装飾より「計算ロジックと保存の正しさ」を最優先すること。
- テスト検証時は、誰でも一瞬で暗算できるキリの良い数字（10,000円、1,000円など）を用いること。
- バグ修正の試行は最大2回までとし、解決しない場合は無理に変更を重ねず、原因を整理して人間に報告すること。
- 1つのフェーズのテストに合格したら、Gitコミット（セーブ）を作成すること。
